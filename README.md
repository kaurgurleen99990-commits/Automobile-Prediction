## 📌 Project Overview

The **Automobile Price Prediction** project is an end-to-end Machine Learning web application that predicts the estimated price of an automobile based on its specifications.

The application is built using **Python**, **Flask**, and **Scikit-learn**, providing users with an intuitive web interface to enter vehicle details and instantly receive a predicted automobile price.

This project demonstrates the complete machine learning workflow including:

- Data preprocessing
- Feature engineering
- Model training
- Model evaluation
- Model deployment using Flask
- Interactive web interface

# 📊 Dataset

The project uses an automobile dataset containing several vehicle attributes such as:

- Car Brand
- Fuel Type
- Engine Size
- Horsepower
- Mileage
- Number of Doors
- Body Style
- Transmission
- Fuel Efficiency
- Engine Specifications

These features are used to train a regression model for predicting automobile prices.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Automobile-Prediction.git
```

Go inside the project

```bash
cd Automobile-Prediction
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the Flask application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
